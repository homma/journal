### D 言語から SDL3 を利用する
> date: 2026-03-29  
> topics: d

`ImportC` を使用して、D 言語のプログラムから SDL3 を利用します。

#### sdl3.c
````c
#include <SDL3/SDL.h>
````

#### main.d
````d
import std.string : toStringz;
import std.stdio : writeln;
import sdl3;

auto main() {

  if (!SDL_Init(SDL_INIT_VIDEO)) {
    writeln("error");
    return 1;
  }

  auto title = "My SDL3 Window".toStringz;
  auto width = 600;
  auto height = 400;
  auto flags = 0;

  auto win = SDL_CreateWindow(title, width, height, flags);

  SDL_Event event;
  auto quit = false;

  while (quit != true) {
    while (SDL_PollEvent(&event)) {
      if (event.type == SDL_EVENT_QUIT) {
        quit = true;
      }
    }
  }

  win.SDL_DestroyWindow;
  SDL_Quit;

  return 0;
}
````

#### dub.sdl
````sdlang
name "d_sdl3"
targetType "executable"
mainSourceFile "main.d"
libs "sdl3"
cImportPaths `${INC_PATH}`
````

#### build.sh
````sh
#!/bin/sh -x

INC_PATH=$(brew --prefix sdl3)/include dub build
````

#### ビルド
````console
$ chmod +x ./build.sh
$ ./build.sh
````

#### Ref
- https://dlang.org/spec/importc.html

### 型が構造体かクラスかを確認する
> date: 2026-03-29  
> topics: d

#### main.d
````d
import std.stdio : writeln;

struct Foo {};

alias T = Foo;

auto main() {

  string t;

  static if (is(T == struct)) {
    t = "struct";
  } else static if (is(T == class)) {
    t = "class";
  } else static if (is(T == union)) {
    t = "union";
  } else static if (is(T == enum)) {
    t = "enum";
  } else {
    t = "unknown";
  }

  t.writeln;

  TypeInfo tid = typeid(T);
  t = tid.toString;

  t.writeln;

}
````

- https://dlang.org/spec/expression.html#typeid_expressions
- https://dlang.org/spec/expression.html#is_expression
- https://wiki.dlang.org/Is_expression


````d
    auto str = "こんにちは!";
````

### ldc2 のインストールおよびアップデート
> date: 2026-03-29  
> topics: d

#### GitHub リリースを確認
- https://github.com/ldc-developers/ldc/releases

#### 最新バージョンの URL を確認
- https://github.com/ldc-developers/ldc/releases/download/v1.42.0/ldc2-1.42.0-osx-arm64.tar.xz

#### ダウンロード
````console
$ cd somewhere/Applications/Dlang/ldc/
$ curl -L -# -O https://github.com/ldc-developers/ldc/releases/download/v1.42.0/ldc2-1.42.0-osx-arm64.tar.xz
````

#### 展開
````console
$ tar xf ldc2-1.42.0-osx-arm64.tar.xz
````

#### リンク
````console
$ rm ~/.local/ldc
$ ln -s ${PWD}/ldc2-1.42.0-osx-arm64 ~/.local/ldc
````

#### DUB 用のディレクトリ作成
````console
$ cd somewhere/Applications/Dlang/
$ mkdir .dub
$ ln -s ${PWD}/.dub ~/
````

#### パス設定

.zshrc
````shell
# Dlang
PATH=${PATH}:${HOME}/.local/ldc/bin
````

#### 動作確認
````console
$ ldc2 -h
$ rdmd -h
````
