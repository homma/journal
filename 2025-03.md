### Godot でボタンを作成する
> date: 2025-03-22  
> topics: godot

`EditorScript` を使ってボタンを作成します。  
ボタンをクリックするとログが出力されます。  

#### 準備

````console
$ mkdir myproj
$ touch myproj/project.godot
$ vi myproj/myscript.gd
$ vi myproj/myutil.gd
$ vi myproj/mybutton.gd
$ godot myproj/project.godot
````

#### 実行

Godot エディタで `myscript.gd` ファイルを開いて実行  
作成されたシーンを実行

#### スクリプト

myscript.gd
````gdscript
@tool
extends EditorScript

const myutil = preload("res://myutil.gd")

func _run():
    var root = create_node_tree()
    myutil.create_scene_from_node(root, "myscene")

func create_node_tree():
    # root / Control
    var root = ClassDB.instantiate("Control")
    root.set_name("root")
    root.position = Vector2(0, 0)
    root.size = Vector2(100, 100)

    # child / Button
    var button = ClassDB.instantiate("Button")
    button.set_name("button")
    button.text = "ボタン"
    button.size = Vector2(100, 40)
    ## スクリプトのアタッチ
    button.set_script(load("res://mybutton.gd"))
    ## シグナルの接続
    button.pressed.connect(Callable(button, "_button_pressed"), Object.CONNECT_PERSIST)
    ## root ノードに追加
    root.add_child(button)
    ## シーンに追加
    button.set_owner(root)

    return root
````

mybutton.gd
````gdscript
extends Button

func _button_pressed():
    print("ボタンがクリックされました")
````

myutil.gd
````gdscript
# create a scene from a node
static func create_scene_from_node(root_node, scene_name):
    # PackedScene
    var scn = PackedScene.new()
    scn.pack(root_node)

    var path = "res://" + scene_name + ".tscn"

    var n = 0
    while FileAccess.file_exists(path):
        n += 1
        path = "res://" + scene_name + str(n) + ".tscn"

    # save the PackedScene
    ResourceSaver.save(scn, path)

    # open the PackedScene in the editor
    EditorInterface.open_scene_from_path(path)
````

### Godot で画面に文字を表示する
> date: 2025-03-22  
> topics: godot

`EditorScript` を使って文字列を表示します。  
文字列の表示は `Label` を使用します。  

#### 準備

````console
$ mkdir myproj
$ touch myproj/project.godot
$ vi myproj/myscript.gd
$ vi myproj/myutil.gd
$ godot myproj/project.godot
````

#### 実行

Godot エディタで `myscript.gd` ファイルを開いて実行  
作成されたシーンを実行

#### スクリプト

myscript.gd
````gdscript
@tool
extends EditorScript

const myutil = preload("res://myutil.gd")

func _run():
    var root = create_node_tree()
    myutil.create_scene_from_node(root, "myscene")

func create_node_tree():
    # root / Control
    var root = ClassDB.instantiate("Control")
    root.set_name("root")
    root.position = Vector2(0, 0)
    root.size = Vector2(300, 300)

    # child / Label
    var label = ClassDB.instantiate("Label")
    label.set_name("label")
    label.text = "こんにちは"
    label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
    label.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
    label.set_anchors_preset(Control.PRESET_FULL_RECT)
    root.add_child(label)
    label.set_owner(root)

    return root
````

### Panda3D を C++ プロジェクト用にインストールする
> date: 2025-03-15  
> topics: c++, panda3d  

Panda3D SDK のインストーラーには arm64 版のライブラリは含まれていない模様。  
そのため、ヘッダーファイルは Python3D SDK のインストーラーから抽出し、ライブラリは Python のパッケージからコピーする。  

#### C++ 用のヘッダーファイルのインストール

最新版の SDK の URL を確認

- https://www.panda3d.org/download/latest

SDK のダウンロード。  
`headers.pkg` にヘッダーファイルが含まれている。  

ライブラリは `base.pkg` に含まれているが、x86_64 用のため、使用できない。  

````console
$ SDK_URL=https://www.panda3d.org/download/panda3d-1.10.15/Panda3D-SDK-1.10.15-MacOSX10.9.dmg
$ SDK_DMG=Panda3D-SDK-1.10.15-MacOSX10.9.dmg
$ curl -# -L -O ${SDK_URL}
$ hdiutil attach ${SDK_DMG}
$ cp /Volumes/Panda3D\ SDK\ 1.10.15/Panda3D.mpkg/Contents/Packages/headers.pkg .
$ hdiutil info
$ hdiutil detach /Volumes/Panda3D\ SDK\ 1.10.15
$ rm ${SDK_DMG}
````

ヘッダーファイルの抽出

````console
$ pkgutil --expand-full headers.pkg out.headers
$ mv out.headers/Payload/Library/Developer/Panda3D .
$ rm -rf out.*
$ rm *.pkg
````

#### arm64 のライブラリをコピーする

Panda3D SDK インストーラーに含まれているライブラリは x86_64 用。  
arm64 用のライブラリを Python のパッケージからコピーする。  

まだパッケージのインストールを実施していない場合は pip でインストールする。  

````console
$ pip3 install panda3d
````

arm64 用のライブラリをコピーする。  

````console
$ mkdir Panda3D/lib
$ PY_DIR=$(python3 -c 'import site;print(site.USER_SITE)')
$ cp -Rp ${PY_DIR}/panda3d/lib*.dylib Panda3D/lib
$ cp -Rp ${PY_DIR}/panda3d_tools/libp3framework.1.10.dylib Panda3D/lib
````

必要なライブラリにリンクを張る。  

````
$ cd Panda3D/lib
$ VER=1.10; for i in panda pandafx pandaexpress p3dtoolconfig p3dtool p3direct p3framework; do ln -s lib${i}.${VER}.dylib lib${i}.dylib; done
````

#### C++ プログラムのコンパイル

````console
$ vi myapp.cxx
````

````console
$ g++ myapp.cxx -o myapp -std=c++11 -IPanda3D/include -LPanda3D/lib -lpanda -lpandafx -lpandaexpress -lp3dtoolconfig -lp3dtool -lp3direct -lp3framework
````

#### C++ プログラムの実行

````console
$ DYLD_LIBRARY_PATH=Panda3D/lib ./myapp
````

#### 参考情報

macOS 版の Panda3D SDK が arm64 に対応するのは 1.11 からの模様。  

- https://www.panda3d.org/blog/sdk-1-10-8-release/

### pip を使用できるように設定する
> date: 2025-03-15  
> topics: python  

Homebrew で Python を使用していると pip3 コマンドの実行時に警告が表示されます。  
パッケージをユーザーインストールする分には問題は発生しないため、警告が表示されないように設定します。  

#### 設定手順

````console
$ mkdir -p ~/.config/pip
$ touch ~/.config/pip/pip.conf
````

#### 設定内容

````ini
# ~/.config/pip/pip.conf

[global]
break-system-packages = true
user = true
````

#### テスト

````console
$ pip3 install pycowsay
$ type pycowsay
$ pip3 uninstall -y pycowsay
````
