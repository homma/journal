### C++ から raygui を使用する
> date: 2025-04-16  
> topics: c++, raylib, raygui

### raygui を使用する手順

#### raylib のインストール

````console
$ brew install raylib
````

#### raygui のダウンロード

````console
$ git clone https://github.com/raysan5/raygui.git
````

#### main.cpp

````cpp
#include <print>
#include <raylib.h>

#define RAYGUI_IMPLEMENTATION
#include <raygui.h>

auto draw_ui() -> void {
  auto bg_color = GetColor(GuiGetStyle(DEFAULT, BACKGROUND_COLOR));
  ClearBackground(bg_color);

  if (GuiButton(Rectangle{200, 160, 200, 80}, "My Button")) {
    std::println("My Button pushed.");
  }
}

auto update() -> void {
  BeginDrawing();

  draw_ui();

  EndDrawing();
}

auto main() -> int {
  InitWindow(600, 400, "My Raygui Window");

  while (!WindowShouldClose()) {
    update();
  }

  CloseWindow();
}
````

#### コンパイルと実行

````console
$ clang++ main.cpp -o test_raygui -Iraygui/src -I$(brew --prefix raylib)/include -L$(brew --prefix raylib)/lib -lraylib -std=c++2c
$ ./test_raygui
````

### git リポジトリにサブモジュールとして raygui を追加する

#### git リポジトリを構成する

````console
$ git init
````

#### raygui をサブモジュールとして追加する

````console
$ git submodule add https://github.com/raysan5/raygui.git
$ git commit -m "raygui added"
````

### scons でビルドする

#### SConstruct ファイル

````python
import subprocess

# Config
target_name = "test_raygui"
src = "main.cpp"

# Library
## raylib
raylib = {}
raylib["lib"] = "raylib"
raylib["path"] = (
    subprocess.Popen(["brew", "--prefix", "raylib"], stdout=subprocess.PIPE)
    .stdout.read()
    .decode("UTF-8")
    .strip()
)
raylib["lib_path"] = raylib["path"] + "/lib"
raylib["include_path"] = raylib["path"] + "/include"

## raygui
raygui = {}
raygui["include_path"] = "raygui/src"

# Executable
Program(
    target_name,
    src,
    LIBS=[raylib["lib"]],
    LIBPATH=[raylib["lib_path"]],
    CPPPATH=[raylib["include_path"], raygui["include_path"]],
    CCFLAGS=["-std=c++2c"],
)
````

#### ビルドと実行

````console
$ scons
$ ./test_raygui
````

### C++ から SDL3 を使用する
> date: 2025-04-13  
> topics: c++, sdl3  

#### SDL3 のインストール

````console
$ brew install sdl3
````

#### SConstruct
````python
import subprocess

# Executable
target_name = "sdl_test"
src = "main.cpp"

# Library
## SDL3
sdl3 = {}
sdl3["lib"] = "SDL3"
sdl3["path"] = (
    subprocess.Popen(["brew", "--prefix", "sdl3"], stdout=subprocess.PIPE)
    .stdout.read()
    .decode("UTF-8")
    .strip()
)
sdl3["lib_path"] = sdl3["path"] + "/lib"
sdl3["include_path"] = sdl3["path"] + "/include"

Program(
    target_name,
    src,
    LIBS=[sdl3["lib"]],
    LIBPATH=[sdl3["lib_path"]],
    CPPPATH=[sdl3["include_path"]],
    CCFLAGS=["-std=c++2c"],
)
````

#### main.cpp
````cpp
#include <SDL3/SDL.h>
#include <print>

auto main() -> int {
  auto v = SDL_GetVersion();
  std::println("{}.{}.{}", SDL_VERSIONNUM_MAJOR(v), SDL_VERSIONNUM_MINOR(v),
               SDL_VERSIONNUM_MICRO(v));
}
````

#### ビルドと実行
````console
$ scons
$ ./sdl_test
3.2.10
````
