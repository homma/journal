### EditorScript でシーンを新規作成する rev.2
> date: 2024-12-29  
> topics: godot

#### 概要

EditorScript で新しいシーンを作成します  
一時ファイルを作成する方法をやめ、関数にまとめて利用しやすくしました  

#### スクリプト

````gdscript
@tool
extends EditorScript

func _run():
    create_scene("my_new_scene", "Node3D")

func create_scene(scene_name: String, root_class: String):
    # root node
    var root = ClassDB.instantiate(root_class)
    root.set_name(root_class)

    # PackedScene
    var scn = PackedScene.new()
    scn.pack(root)

    var path = "res://" + scene_name + ".tscn"

    var n = 0
    while FileAccess.file_exists(path):
          n += 1
          path = "res://" + scene_name + str(n) + ".tscn"

    # save the PackedScene
    ResourceSaver.save(scn, path)

    # open the PackedScene in the editor
    EditorInterface.open_scene_from_path(path)
````

### EditorScript でシーンを新規作成する
> date: 2024-12-28  
> topics: godot

#### 概要

EditorScript で新しいシーンを作成します

これを実現する簡単な方法がないため、以下を実施しています
- シーンの root ノードとなるノードを作成
- PackedScene を作成し、ノードを登録
- PackedScene をファイルシステムに一時保存
- 保存した PackedScene をエディターから開く
- PackedScene の一時保存に使用したファイルを削除

#### スクリプト

````gdscript
@tool
extends EditorScript

func _run():
    # root node
    var node = Node3D.new()
    node.set_name("Node3D")

    # PackedScene
    var scn = PackedScene.new()
    scn.pack(node)

    # create a temporary file to store the PackedScene
    var time = Time.get_ticks_msec()
    var path = "res://tmp" + str(time) + ".tscn"
    ResourceSaver.save(scn, path)

    # open the PackedScene in the editor
    EditorInterface.open_scene_from_path(path)

    # remove the temporary file
    DirAccess.remove_absolute(path)
    EditorInterface.get_resource_filesystem().scan()
````

### EditorScript でノードを追加する
> date: 2024-12-28  
> topics: godot

#### 概要

Godot の EditorScript を使用して以下の構成のシーンを作成します

````
- CharacterBody3D
  - MeshInstance3D(BoxMesh)
  - CollisionShape3D(BoxShape3D)
````

#### スクリプト

````gdscript
@tool
extends EditorScript

func _run():
    var size = Vector3(1, 5, 10)
    var position = Vector3(0, 2.5, 0)

    # Character
    var body = CharacterBody3D.new()
    body.show()
    
    # Mesh
    var box = MeshInstance3D.new()
    var box_mesh = BoxMesh.new()
    box_mesh.set_size(size)
    box.set_mesh(box_mesh)
    box.set_position(position)
    body.add_child(box)
    box.set_owner(body)

    # Collision Shape
    var coll = CollisionShape3D.new()
    var box_shape = BoxShape3D.new()
    box_shape.set_size(size)
    coll.set_shape(box_shape)
    coll.set_position(position)
    body.add_child(coll)
    coll.set_owner(body)

    add_root_node(body)
````

### Rust から SDL2 を使用してウィンドウを開く
> date: 2024-12-14  
> topics: rust, sdl2

#### 事前準備

````console
$ cargo new sdl_win_test
$ cd sdl_win_test
$ cargo add sdl2-sys --features use-pkgconfig,use-bindgen
````

#### `main.rs` の作成

````console
$ vi src/main.rs
````

````rust
// main.rs

use sdl2_sys::*;
use std::mem;

fn main() {
    if unsafe { SDL_Init(SDL_INIT_VIDEO) } < 0 {
        panic!("cannot initialize SDL.")
    }

    let win = {
        let title = c"My SDL2 Window".as_ptr();
        let x = SDL_WINDOWPOS_CENTERED_MASK as i32;
        let y = SDL_WINDOWPOS_CENTERED_MASK as i32;
        let w = 480;
        let h = 320;
        let flags = 0;

        unsafe { SDL_CreateWindow(title, x, y, w, h, flags) }
    };

    loop {
        let quit = update();
        if quit {
            unsafe {
                SDL_DestroyWindow(win);
                SDL_Quit();
            }
            break;
        }
        unsafe { SDL_Delay(100) };
    }
}

fn update() -> bool {
    let mut quit = false;
    let mut event: SDL_Event = unsafe { mem::zeroed() };

    while unsafe { SDL_PollEvent(&mut event) } != 0 {
        match unsafe { event.type_ } {
            x if x == SDL_EventType::SDL_QUIT as u32 => {
                quit = true;
            }
            _ => (),
        }
    }

    quit
}
````

#### ビルドと実行

````console
$ cargo check
$ cargo fmt
$ cargo build
$ cargo run
````

### Rust から SDL2 を使用する
> date: 2024-12-13  
> topics: rust, sdl2

Rust から SDL2 を使用する方法は 3 種類あると思います。

1. sdl2 crate を使用する
2. sdl2-sys create を使用する
3. bindgen を使用する

今回は 2 番目の方法で Rust から SDL2 を呼び出す方法です。

#### 事前準備

Homebrew を使用して SDL2 と pkg-config をインストールします。

````console
$ brew install sdl2
$ brew install pkg-config
````

#### 新規プロジェクトの作成

````console
$ cargo new sdl_test
$ cd sdl_test
````

#### sdl2-sys crate の追加

`sdl2-sys` crate を追加するため `cargo add` コマンドを実行します。  
SDL2 ライブラリの検索に `pkg-config` コマンドを使用するため、use-pkgconfig を features に追加しています。  
SDL2 への binding を再生成するため、use-bindgen を features に追加しています。

````console
$ cargo add sdl2-sys --features use-pkgconfig,use-bindgen
````

#### `main.rs` の作成

````console
$ vi src/main.rs
````

`SDL_GetVersion` 関数を呼び出してバージョンを出力するだけの簡単なプログラムです。  

````rust
// main.rs

fn main() {
    test();
}

fn test() {
    let major = 0;
    let minor = 0;
    let patch = 0;
    let mut ver = sdl2_sys::SDL_version {
        major,
        minor,
        patch,
    };
    unsafe { sdl2_sys::SDL_GetVersion(&mut ver) };
    println!("{}.{}.{}", ver.major, ver.minor, ver.patch);
}
````

#### ビルドと実行

````console
$ cargo check
$ cargo fmt
$ cargo build
$ cargo run
````
