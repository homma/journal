### Rust から SDL2 を使用してウィンドウを開く
> date: 2024-12-14  
> topics: rust, sdl2

#### 事前準備

````sh
$ cargo new sdl_win_test
$ cd sdl_win_test
$ cargo add sdl2-sys --features use-pkgconfig,use-bindgen
````

#### `main.rs` の作成

````sh
$ vi src/main.rs
````

````rust
// main.rs

use sdl2_sys::*;
use std::mem;

fn main() {
    if unsafe { SDL_Init(SDL_INIT_VIDEO) } < 0 {
        panic!("cannot initialize SDL.")
    }

    let win = {
        let title = c"My SDL2 Window".as_ptr();
        let x = SDL_WINDOWPOS_CENTERED_MASK as i32;
        let y = SDL_WINDOWPOS_CENTERED_MASK as i32;
        let w = 480;
        let h = 320;
        let flags = 0;

        unsafe { SDL_CreateWindow(title, x, y, w, h, flags) }
    };

    let mut event: SDL_Event = unsafe { mem::zeroed() };
    let mut quit = false;

    while !quit {
        while unsafe { SDL_PollEvent(&mut event) } != 0 {
            match unsafe { event.type_ } {
                x if x == SDL_EventType::SDL_QUIT as u32 => {
                    unsafe {
                        SDL_DestroyWindow(win);
                        SDL_Quit();
                    }
                    quit = true;
                }
                _ => (),
            }
        }
        unsafe { SDL_Delay(100) };
    }
}
````

#### ビルドと実行

````sh
$ cargo check
$ cargo fmt
$ cargo build
$ cargo run
````

### Rust から SDL2 を使用する
> date: 2024-12-13  
> topics: rust, sdl2

Rust から SDL2 を使用する方法は 3 種類あると思います。

1. sdl2 crate を使用する
2. sdl2-sys create を使用する
3. bindgen を使用する

今回は 2 番目の方法で Rust から SDL2 を呼び出す方法です。

#### 事前準備

Homebrew を使用して SDL2 と pkg-config をインストールします。

````sh
$ brew install sdl2
$ brew install pkg-config
````

#### 新規プロジェクトの作成

````sh
$ cargo new sdl_test
$ cd sdl_test
````

#### sdl2-sys crate の追加

`sdl2-sys` crate を追加するため `cargo add` コマンドを実行します。  
SDL2 ライブラリの検索に `pkg-config` コマンドを使用するため、use-pkgconfig を features に追加しています。  
SDL2 への binding を再生成するため、use-bindgen を features に追加しています。

````sh
$ cargo add sdl2-sys --features use-pkgconfig,use-bindgen
````

#### `main.rs` の作成

````sh
$ vi src/main.rs
````

`SDL_GetVersion` 関数を呼び出してバージョンを出力するだけの簡単なプログラムです。  

````rust
// main.rs

fn main() {
    test();
}

fn test() {
    let major = 0;
    let minor = 0;
    let patch = 0;
    let mut ver = sdl2_sys::SDL_version {
        major,
        minor,
        patch,
    };
    unsafe { sdl2_sys::SDL_GetVersion(&mut ver) };
    println!("{}.{}.{}", ver.major, ver.minor, ver.patch);
}
````

#### ビルドと実行

````sh
$ cargo check
$ cargo fmt
$ cargo build
$ cargo run
````
