### scons を試す
> date: 2025-02-11  
> topics: c++, scons, sdl2  

#### 概要

`scons` を使用して C++ のプログラムをビルドしてみます

#### sdl_test.cpp

````cpp
#include <print>
#include <SDL2/SDL.h>

auto main() -> int {
  auto v = SDL_version{};
  SDL_GetVersion(&v);
  std::println("{}.{}.{}", v.major, v.minor, v.patch);
}
````

#### SConstruct

````python
import subprocess

# Executable
target_name = "sdl_test"
src = "sdl_test.cpp"

# Library
## SDL2
sdl_lib = "SDL2"
sdl_path = (
    subprocess.Popen(["brew", "--prefix", "sdl2"], stdout=subprocess.PIPE)
    .stdout.read()
    .decode("UTF-8")
    .strip()
)
sdl_lib_path = sdl_path + "/lib"
sdl_include_path = sdl_path + "/include"

Program(
    target_name,
    src,
    LIBS=[sdl_lib],
    LIBPATH=[sdl_lib_path],
    CPPPATH=[sdl_include_path],
    CCFLAGS=["-std=c++2c"],
)
````

#### インストール

````console
$ brew install scons
````

#### ビルド

````console
$ scons
````

#### クリーンアップ

````console
$ scons -c
````

### clang-repl で SDL2 を使用する
> date: 2025-02-10  
> topics: c++, sdl2

#### 概要

`clang-repl` から SDL2 の関数を呼び出してみます

#### 実行

````console
$ export DYLD_LIBRARY_PATH=$(brew --prefix sdl2)/lib
$ clang-repl --Xcc=-I$(brew --prefix sdl2)/include
%lib libSDL2.dylib
#include <SDL2/SDL.h>
auto v = SDL_version{};
SDL_GetVersion(&v);
#include <print>
std::println("{}.{}.{}", v.major, v.minor, v.patch);
2.30.12
````

### clang-repl を試す
> date: 2025-02-09  
> topics: c++

#### 概要

`clang-repl` の動作を試してみます

#### インストール

````console
$ brew install llvm
$ alias clang-repl="$(brew --prefix llvm)/bin/clang-repl --Xcc=-std=c++2c"
````

#### 実行

````console
$ clang-repl 
clang-repl> #include <print>
clang-repl> std::println("hello");
hello
````
